# CSV to Excel Converter

A Python command-line tool that converts CSV files into Excel workbooks using pandas and openpyxl.

## Features
- CSV reading and Excel export
- Missing-value handling and duplicate removal
- Column-name normalization and renaming
- Date parsing
- Command-line input and output options
- Logging and error handling

## Installation
```bash
python -m pip install -r requirements.txt
```

## Usage
```bash
python csv_to_excel.py --input sample_data.csv --output output.xlsx
```
